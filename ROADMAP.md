# Roadmap

What is next, in order. Dates are intentions, not promises. Open an issue to argue for a change.

## Now (November 2026)

- Public release of this repository.
- Connector contract: every connector read-only, checked in CI (done).
- One-command self-host, tested end to end on every change (done).
- Shopify dashboard tab.

## Next

- Scheduled report delivery (email a PDF on a schedule).
- Anomaly alerts (a metric moves more than usual; notify).
- Google Sheets export.
- More connectors: LinkedIn Ads, TikTok Ads, Microsoft Ads, Mailchimp. Vote in Issues.

## Later

- Client portal (a read-only login for the client).
- One stack for cloud and self-host (leave Supabase hosting, keep Postgres).
- White-label domains.

## Not planned

- Writing back to any platform (pausing campaigns, editing budgets). Braidscope reads.
